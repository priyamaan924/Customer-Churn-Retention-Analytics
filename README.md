# Customer Churn & Retention Analytics

## Project Overview
This project analyzes customer churn and retention using Excel, MySQL, Python, and Power BI. It aims to identify churn patterns, understand customer behavior, and highlight factors associated with customer attrition.

## Objectives
- Calculate key customer churn and retention KPIs.
- Analyze churn across contract types, tenure, and payment methods.
- Identify customer groups with higher churn rates.
- Present insights through a Power BI dashboard.

## Tools & Technologies
- **Excel:** Data analysis, KPI calculations, and summaries
- **MySQL:** Data querying and churn analysis
- **Python:** Data cleaning, analysis, and visualization
- **Power BI:** Interactive dashboard and data visualization

## Dataset
The project uses the IBM Telco Customer Churn dataset, containing customer demographics, services, contract details, charges, tenure, and churn status.

- Total records: 7,043 customers
- Target variable: `Churn` (`Yes` or `No`)

## Key Metrics
- **Total Customers:** 7,043
- **Churned Customers:** 1,869
- **Churn Rate:** 26.54%
- **Retention Rate:** 73.46%

## Analysis Performed
- Overall churn and retention analysis
- Churn by contract type
- Tenure analysis by churn status
- Churn by payment method
- Customer revenue and churn-related analysis

## Dashboard
The Power BI dashboard presents key performance indicators and visual comparisons of customer churn and retention. Dashboard screenshots are available in the `screenshots` folder.

## Key Findings
- Month-to-month customers show substantially higher churn than customers on longer-term contracts.
- Two-year contract customers have the lowest observed churn rate among the contract groups analyzed.
- Customer tenure and payment method are examined to understand churn patterns.

## Conclusion
This project demonstrates an end-to-end data analytics workflow, from dataset analysis and SQL querying to Python visualization and interactive Power BI reporting.
